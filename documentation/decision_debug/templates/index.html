Criteria weights

Weights are normalised by the engine. Live % shows each criterion's share of the total. The curve above each slider is that weight's sampling spread — it widens as weight perturbation increases.

Each criterion carries an explicit state field, shown by the badge next to its name:

  • active participates directly in the ranking with its (positive) weight.
  • dormant no preference expressed yet. The engine only gives it weight via the dormant budget (sampled 0…budget per iteration), and it generates discovery questions. Dragging a slider to 0 returns a criterion to this state.
  • excluded DON'T CARE — explicitly excluded via the don't care toggle. Dropped from the ranking, dormant exploration, and discovery questions. Toggle again to bring it back.

State is explicit, not encoded in the weight: a slider > 0 emits set_weight (active), a slider at 0 emits set_state: dormant, and the don't care toggle emits set_state: excluded.

Dormant / advanced criteria

Left at 0 these stay dormant (explored via the dormant budget). Raise a slider above 0 to activate the criterion.
target = scored by closeness to an ideal value (not highest/lowest). Set a target value to activate the criterion (defaults to weight 0.05).
